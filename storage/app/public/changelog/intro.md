# Journal des versions KrosmozJDR

Les entrées suivent une **semver courte** (**X.Y.Z**). Une section « **Navigation des versions** » est automatiquement insérée par l’agrégateur web (`GET /changelog/feed/{version}`) pour passer d’un fichier à un autre sans URL absolues de développement.

Rédige pour les **joueurs et MJ** : ce qui change à l’usage du site, sans détails techniques (réservés à la documentation interne `/docs/`).
