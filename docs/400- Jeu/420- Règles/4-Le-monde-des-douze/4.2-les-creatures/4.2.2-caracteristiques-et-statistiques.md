# 4.2.2. Caractéristiques et statistiques

**Description** : tout ce qui fait « tourner » une créature en chiffres : caractéristiques, [[kref:characteristic:life_points_creature|PV]], résistances, et comment les ramener depuis le jeu vidéo sans te prendre la tête.

> **Règles rapides - Caractéristiques et statistiques**
> - **Caractéristiques** (clés) : [[kref:characteristic:strength_creature|Force]] (`strength_creature`), [[kref:characteristic:intelligence_creature|Intelligence]] (`intelligence_creature`), [[kref:characteristic:wisdom_creature|Sagesse]] (`wisdom_creature`), [[kref:characteristic:agility_creature|Agilité]] (`agility_creature`), [[kref:characteristic:chance_creature|Chance]] (`chance_creature`), [[kref:characteristic:vitality_creature|Vitalité]] (`vitality_creature`)
> - **Ressources de combat** : [[kref:characteristic:action_points_creature|PA]] (`action_points_creature`), [[kref:characteristic:movement_points_creature|PM]] (`movement_points_creature`), [[kref:characteristic:range_creature|PO]] (`range_creature`), initiative (`initiative_creature`)
> - **Défenses** : [[kref:characteristic:life_points_creature|PV]], boucliers, résistances réduites/augmentées
> - **Adaptation Dofus** : Conversion rapide depuis les stats du jeu vidéo
> - **Ajustements MJ** : Possibilité d'ajuster selon le niveau des personnages

## Contenu

Tout ce qu'il te faut pour lire (et ajuster) une fiche de créature :

- **4.2.2.1. Caractéristiques de base** : [[kref:characteristic:strength_creature|Force]], [[kref:characteristic:intelligence_creature|Intelligence]], etc. adaptées aux créatures.
- **4.2.2.2. Ressources de combat** : [[kref:characteristic:action_points_creature|PA]], [[kref:characteristic:movement_points_creature|PM]], [[kref:characteristic:range_creature|PO]], initiatives spécifiques.

## 4.2.2.1. Caractéristiques de base

Bonne nouvelle : tu retrouves le même vocabulaire que pour les PJ, avec des valeurs calibrées sur la nature du monstre. Pas de jargon supplémentaire à apprendre !

### Les six caractéristiques

Même schéma que les PJ — détail narratif : [2.2.1 — Caractéristiques principales](../../2-Creer-un-personnage/2.2-les-caracteristiques/2.2.1-caracteristiques-principales.md), secondaires : [2.2.2](../../2-Creer-un-personnage/2.2-les-caracteristiques/2.2.2-caracteristiques-secondaires.md).

**[[kref:characteristic:strength_creature|Force]]** (`strength_creature`) :
- **Usage** : Dégâts physiques, tests d'[[kref:characteristic:athletics_creature|Athlétisme]]
- **Créatures fortes** : Bouftous, Craqueleurs, créatures de combat
- **Valeurs typiques** : Variable selon le type de créature

**[[kref:characteristic:intelligence_creature|Intelligence]]** (`intelligence_creature`) :
- **Usage** : Sorts, tests de connaissances
- **Créatures intelligentes** : Mages, créatures magiques, humanoïdes
- **Valeurs typiques** : Variable selon le type de créature

**[[kref:characteristic:wisdom_creature|Sagesse]]** (`wisdom_creature`) :
- **Usage** : [[kref:characteristic:perception_creature|Perception]], tests de [[kref:characteristic:wisdom_creature|Sagesse]]
- **Créatures sages** : Créatures anciennes, gardiens, sages
- **Valeurs typiques** : Variable selon le type de créature

**[[kref:characteristic:agility_creature|Agilité]]** (`agility_creature`) :
- **Usage** : Vitesse, esquive, tests d'[[kref:characteristic:agility_creature|Agilité]]
- **Créatures agiles** : Wabbits, créatures rapides, furtives
- **Valeurs typiques** : Variable selon le type de créature

**[[kref:characteristic:chance_creature|Chance]]** (`chance_creature`) :
- **Usage** : Tests de [[kref:characteristic:chance_creature|Chance]], effets aléatoires
- **Créatures chanceuses** : Créatures magiques, créatures rares
- **Valeurs typiques** : Variable selon le type de créature

**[[kref:characteristic:vitality_creature|Vitalité]]** (`vitality_creature`) :
- **Usage** : [[kref:characteristic:life_points_creature|Points de vie]], résistance aux effets
- **Toutes les créatures** : Toutes les créatures ont de la [[kref:characteristic:vitality_creature|Vitalité]]
- **Valeurs typiques** : Variable selon le type et le niveau

### Adaptation depuis Dofus

Tu peux t'inspirer des fiches vidéo pour gagner du temps : garde les ordres de grandeur, puis équilibre pour que la rencontre reste fun autour de la table.

**Conversion** :
- **Niveau** : Le niveau de la créature dans Dofus correspond généralement au niveau dans le JDR
- **Caractéristiques** : Les caractéristiques sont adaptées proportionnellement
- **Équilibrage** : Les valeurs sont ajustées pour l'équilibre du JDR

**Exemples** :
- **Bouftou niveau 10** : Caractéristiques adaptées pour un niveau 10
- **Boss niveau 50** : Caractéristiques adaptées pour un niveau 50
- **Créature faible** : Caractéristiques réduites pour les créatures faibles

## 4.2.2.2. Ressources de combat

Même tempo qu'avec tes PJ : [[kref:characteristic:action_points_creature|PA]], [[kref:characteristic:movement_points_creature|PM]], initiative… tu gardes tes habitudes de lecture en combat.

### Points d'Action ([[kref:characteristic:action_points_creature|PA]])

> **Clé** : `action_points_creature`

**Fonctionnement** :
- **Utilisation** : Identique aux personnages
- **Valeurs** : Variable selon le type de créature
- **Régénération** : Généralement régénérés chaque tour

**Exemples** :
- **Créature faible** : 3-4 [[kref:characteristic:action_points_creature|PA]]
- **Créature moyenne** : 5-6 [[kref:characteristic:action_points_creature|PA]]
- **Créature puissante** : 7-8 [[kref:characteristic:action_points_creature|PA]]
- **Boss** : 8-10 [[kref:characteristic:action_points_creature|PA]] ou plus

### [[kref:characteristic:movement_points_creature|Points de Mouvement]] ([[kref:characteristic:movement_points_creature|PM]])

> **Clé** : `movement_points_creature`

**Fonctionnement** :
- **Utilisation** : Identique aux personnages
- **Valeurs** : Variable selon le type de créature
- **Régénération** : Généralement régénérés chaque tour

**Exemples** :
- **Créature lente** : 2-3 [[kref:characteristic:movement_points_creature|PM]]
- **Créature moyenne** : 4-5 [[kref:characteristic:movement_points_creature|PM]]
- **Créature rapide** : 6-7 [[kref:characteristic:movement_points_creature|PM]]
- **Créature très rapide** : 8+ [[kref:characteristic:movement_points_creature|PM]]

### Points d'Opportunité ([[kref:characteristic:range_creature|PO]])

> **Clé** : `range_creature` (portée ; même clé que dans [2.2.2](../../2-Creer-un-personnage/2.2-les-caracteristiques/2.2.2-caracteristiques-secondaires.md))

**Fonctionnement** :
- **Utilisation** : Identique aux personnages
- **Valeurs** : Variable selon le type de créature
- **Régénération** : Généralement régénérés chaque tour

**Exemples** :
- **Créature standard** : 1-2 [[kref:characteristic:range_creature|PO]]
- **Créature spécialisée** : 3-4 [[kref:characteristic:range_creature|PO]]
- **Boss** : 5+ [[kref:characteristic:range_creature|PO]]

### Initiative

> **Clé** : `initiative_creature`

**Fonctionnement** :
- **Calcul** : Identique aux personnages ([[kref:characteristic:intelligence_creature|Intelligence]] + bonus d'Initiative)
- **Valeurs** : Variable selon le type de créature
- **Ordre de tour** : Détermine l'ordre d'action en combat

**Exemples** :
- **Créature lente** : Initiative faible
- **Créature rapide** : Initiative élevée
- **Boss** : Initiative généralement élevée

## 4.2.2.3. Défenses

Une créature ça encaisse autrement qu'un PJ : garde en tête les boucliers et les résistances pour éviter les combats « plats ».

### [[kref:characteristic:life_points_creature|Points de Vie]] ([[kref:characteristic:life_points_creature|PV]])

> **Clé** : `life_points_creature`

**Fonctionnement** :
- **Calcul** : [[kref:characteristic:vitality_creature|Vitalité]] + modificateurs
- **Valeurs** : Variable selon le type et le niveau
- **Régénération** : Généralement pas de régénération automatique

**Exemples** :
- **Créature faible** : 20-50 [[kref:characteristic:life_points_creature|PV]]
- **Créature moyenne** : 50-100 [[kref:characteristic:life_points_creature|PV]]
- **Créature puissante** : 100-200 [[kref:characteristic:life_points_creature|PV]]
- **Boss** : 200+ [[kref:characteristic:life_points_creature|PV]]

### Boucliers

**Fonctionnement** :
- **Types** : Boucliers magiques, boucliers physiques
- **Valeurs** : Variable selon le type de créature
- **Régénération** : Certains boucliers se régénèrent

**Exemples** :
- **Créature avec bouclier** : 10-50 points de bouclier
- **Créature magique** : Boucliers magiques régénérables
- **Boss** : Boucliers puissants et régénérables

### Résistances

**Résistances réduites** :
- **Fonctionnement** : Réduction des dégâts d'un type spécifique
- **Types** : Résistance au feu, à l'eau, à la terre, à l'air, neutre
- **Valeurs** : Variable selon le type de créature

**Résistances augmentées** :
- **Fonctionnement** : Augmentation des dégâts d'un type spécifique
- **Types** : Vulnérabilité au feu, à l'eau, à la terre, à l'air, neutre
- **Valeurs** : Variable selon le type de créature

**Exemples** :
- **Créature de feu** : Résistance au feu, vulnérabilité à l'eau
- **Créature de glace** : Résistance à l'eau, vulnérabilité au feu
- **Créature neutre** : Pas de résistances particulières

### [[kref:characteristic:armor_class_creature|Classe d'Armure]] ([[kref:characteristic:armor_class_creature|CA]])

**Fonctionnement** :
- **Calcul** : Identique aux personnages
- **Valeurs** : Variable selon le type de créature
- **Sources** : Armure naturelle, équipement, magie

### Bonus de critique

Les créatures (monstres, PNJ) peuvent avoir un **bonus de critique** qui réduit le seuil pour effectuer un critique au jet de touche. Valeurs 0 à 3 : seuil affiché = 20 - bonus (0 = uniquement nat 20, 3 = critique dès 17).

### Bonus de soin

Les créatures peuvent avoir un **bonus de soin** ajouté à chaque soin qu'elles prodiguent. Base 0, modifiable par équipement (anneaux, etc.).

**Exemples** :
- **Créature sans armure** : [[kref:characteristic:armor_class_creature|CA]] basse
- **Créature avec armure naturelle** : [[kref:characteristic:armor_class_creature|CA]] moyenne à élevée
- **Créature avec équipement** : [[kref:characteristic:armor_class_creature|CA]] selon l'équipement

## 4.2.2.4. Ajustements MJ

En MJ, tu peux ajuster les statistiques des créatures pour t'adapter à ton groupe.

### Conversion rapide depuis Dofus

**Méthode simple** :
1. **Niveau** : Utiliser le niveau de la créature dans Dofus
2. **Caractéristiques** : Multiplier par un facteur (ex: niveau × 2 pour les [[kref:characteristic:life_points_creature|PV]])
3. **Ressources** : Adapter selon le type de créature
4. **Ajustements** : Ajuster selon l'équilibre du groupe

**Facteurs de conversion** :
- **[[kref:characteristic:life_points_creature|PV]]** : Niveau × 5-10 selon la robustesse
- **[[kref:characteristic:action_points_creature|PA]]** : 3-6 selon le type
- **[[kref:characteristic:movement_points_creature|PM]]** : 3-6 selon la mobilité
- **Caractéristiques** : Niveau × 1-2 selon le type

### Ajustements selon le groupe

**Groupe faible** :
- **Réduire** : Réduire les [[kref:characteristic:life_points_creature|PV]], les dégâts, les résistances
- **Simplifier** : Simplifier les capacités spéciales
- **Ajuster** : Ajuster le nombre de créatures

**Groupe puissant** :
- **Augmenter** : Augmenter les [[kref:characteristic:life_points_creature|PV]], les dégâts, les résistances
- **Complexifier** : Ajouter des capacités spéciales
- **Ajuster** : Augmenter le nombre de créatures ou ajouter des boss

**Groupe équilibré** :
- **Standard** : Utiliser les statistiques de base
- **Varier** : Varier les types de créatures
- **Adapter** : Adapter selon les forces et faiblesses du groupe

### Exemples de conversion

**Exemple 1 : Bouftou niveau 10** :
- **[[kref:characteristic:life_points_creature|PV]]** : 10 × 5 = 50 [[kref:characteristic:life_points_creature|PV]]
- **[[kref:characteristic:action_points_creature|PA]]** : 4 [[kref:characteristic:action_points_creature|PA]]
- **[[kref:characteristic:movement_points_creature|PM]]** : 3 [[kref:characteristic:movement_points_creature|PM]]
- **[[kref:characteristic:strength_creature|Force]]** : +2
- **[[kref:characteristic:vitality_creature|Vitalité]]** : +3

**Exemple 2 : Boss niveau 50** :
- **[[kref:characteristic:life_points_creature|PV]]** : 50 × 8 = 400 [[kref:characteristic:life_points_creature|PV]]
- **[[kref:characteristic:action_points_creature|PA]]** : 8 [[kref:characteristic:action_points_creature|PA]]
- **[[kref:characteristic:movement_points_creature|PM]]** : 5 [[kref:characteristic:movement_points_creature|PM]]
- **Caractéristiques** : +5 à +8 selon le type
- **Capacités** : Capacités spéciales puissantes
