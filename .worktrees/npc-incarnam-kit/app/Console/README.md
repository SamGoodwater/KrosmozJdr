# Commandes Artisan

Les commandes sont chargées depuis `app/Console/Commands/`. Closures : `routes/console.php`.

La liste, les options et le filtrage UI sont dans **[COMMANDS.md](COMMANDS.md)** (source unique, lue par `App\Console\CommandGuide`).

```bash
php artisan list
php artisan project:dev
php artisan <commande> -h
```

Détails orphelins Media / planning admin : [docs/operations/README.md](../../docs/operations/README.md).
