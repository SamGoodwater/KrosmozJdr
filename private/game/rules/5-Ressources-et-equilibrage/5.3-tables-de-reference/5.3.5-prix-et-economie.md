# 5.3.5. Prix et économie

**Description** : Barèmes de prix (équipements, services), variations régionales, inflation et troc — pour gérer l'économie de ta campagne sans te perdre.

> **Règles rapides - Prix et économie**
> - **Ressources** : prix Dofus, au moins 1 kama si jouable
> - **Consommables** : somme de la recette
> - **Équipements** : Σ (bonus × prix unitaire) + 150 × niveau + 200 × rareté
> - **Services** : Soins (50-200 kamas), téléportations (10-50 kamas), informations (variable)
> - **Variations régionales** : Offres/demandes par zone (modificateurs de prix)
> - **Troc** : Règles pour échanges sans Kamas (valeur relative des objets)

## Contenu

- **5.3.5.1. Prix standard** : Liste indicative par catégorie d'objet.
- **5.3.5.2. Services** : Soins, téléportations, informations.
- **5.3.5.3. Variations régionales** : Offres/demandes par zone.

## 5.3.5.1. Prix standard

Ces barèmes te donnent une base pour fixer ou évaluer les prix en jeu. Les **fiches** du site (équipements, consommables, ressources) portent le prix de référence ; tu peux l’ajuster selon la région (voir plus bas).

### Ressources

Le prix affiché est celui **proposé par Dofus** (import). Pas de formule Krosmoz par-dessus. Une ressource **jouable** vaut au moins **1 kama** (on n’affiche plus 0). Les ingrédients de l’échelle de soin ont un prix calé sur le consommable / 10.

### Consommables

**Règle** : somme des prix des ressources de la recette (quantité × prix de chaque ingrédient). Sans recette, le prix automatique est 0 jusqu’à un ajustement manuel.

**Soins hors combat** (catalogue, 11 paliers identiques pour potion / pain / poisson / viande) :

| PV rendus | Prix du consommable | Prix de la ressource (×10 dans la recette) |
| --- | --- | --- |
| +1 | 20 | 2 |
| +3 | 100 | 10 |
| +5 | 300 | 30 |
| +7 | 600 | 60 |
| +10 | 1 000 | 100 |
| +12 | 1 500 | 150 |
| +15 | 2 000 | 200 |
| +17 | 3 500 | 350 |
| +20 | 5 000 | 500 |
| +25 | 7 000 | 700 |
| +30 | 10 000 | 1 000 |

**Parchemins d’apprentissage** : souvent 2000 × niveau du sort (ex. niveau 13 → 26 000 kamas) si tu n’as pas de recette.

### Équipements

**Formule** :

**Σ (bonus × prix unitaire de la caractéristique) + 150 × niveau + 200 × rareté (0–5).**

Les prix unitaires (Vitalité, Force, PA, etc.) sont ceux du tableau des bonus d’équipement (atelier **Création → Équipements**), pas une table figée dans ce chapitre.

Exemple : un objet niveau 8, rareté Peu commun (1), +2 Force à 1 000 kamas / unité → 2 × 1 000 + 150 × 8 + 200 × 1 = 3 400 kamas.

## 5.3.5.3. Variations régionales

Les prix varient selon l'offre, la demande et l'isolement — tu peux appliquer ces modificateurs.

### Grandes villes

**Caractéristiques** :
- **Concurrence** : Grande concurrence entre vendeurs
- **Prix** : Prix généralement plus bas
- **Disponibilité** : Grande disponibilité d'objets

**Modificateurs** :
- **Achat** : -10% à -20% sur les prix
- **Vente** : -10% à -20% sur les prix de vente
- **Services** : Prix standards

### Petites villes

**Caractéristiques** :
- **Concurrence** : Concurrence limitée
- **Prix** : Prix généralement plus élevés
- **Disponibilité** : Disponibilité limitée

**Modificateurs** :
- **Achat** : +10% à +20% sur les prix
- **Vente** : +10% à +20% sur les prix de vente
- **Services** : Prix standards à légèrement élevés

### Régions reculées

**Caractéristiques** :
- **Concurrence** : Pas de concurrence
- **Prix** : Prix très variables
- **Disponibilité** : Disponibilité très limitée

**Modificateurs** :
- **Achat** : +20% à +50% sur les prix
- **Vente** : -20% à -50% sur les prix de vente
- **Services** : Prix élevés ou indisponibles

### Zones de guerre

**Caractéristiques** :
- **Demande** : Demande élevée pour les armes
- **Prix** : Prix élevés pour les armes
- **Disponibilité** : Disponibilité limitée

**Modificateurs** :
- **Armes** : +50% à +100% sur les prix
- **Armures** : +20% à +50% sur les prix
- **Autres** : Prix variables

## 5.3.5.4. Troc

Quand les Kamas ne suffisent pas, le troc reste une option — surtout en région reculée.

### Règles de base

**Définition** : Échange d'objets sans utiliser de Kamas.

**Utilisation** :
- **Régions reculées** : Plus fréquent dans les régions reculées
- **Objets rares** : Utile pour les objets rares
- **Relations** : Crée des relations avec les PNJ

### Évaluation

**Valeur des objets** :
- **Valeur de base** : Utilise les prix standards
- **Valeur relative** : Adapte selon le contexte
- **Valeur sentimentale** : Prends en compte la valeur sentimentale

**Négociation** :
- **Tests** : Tests de [[kref:characteristic:persuasion_creature|Persuasion]] pour négocier
- **Relations** : Les relations avec le PNJ affectent la négociation
- **Contexte** : Le contexte affecte la négociation

### Exemples

**Échange simple** :
- **Objet A** : Valeur 500 kamas
- **Objet B** : Valeur 500 kamas
- **Échange** : Échange direct

**Échange complexe** :
- **Objet A** : Valeur 1000 kamas
- **Objet B** : Valeur 500 kamas
- **Compensation** : Compensation nécessaire (objets supplémentaires ou Kamas)

**Échange avec relations** :
- **Relations positives** : Meilleur échange possible
- **Relations négatives** : Échange désavantageux
- **Relations neutres** : Échange standard
