# 5.2.2. Classes et spécialisations

**Description** : Des repères pour équilibrer classes (voies, rôles) et spécialisations (capacités, aptitudes), et juger leur puissance de façon cohérente.

> **Règles rapides - Classes et spécialisations**
> - **Rôles** : Vérifier que chaque rôle est couvert (Dégâts, Protection, Soin, Amélioration, Entrave, Placement)
> - **Voies élémentaires** : Répartition des sorts (Feu, Eau, Terre, Air), cohérence thématique
> - **Spécialisations** : Puissance des capacités/aptitudes par niveau (progression équilibrée)
> - **Comparaison** : Méthode pour comparer deux classes/spécialisations (critères objectifs)

## Contenu

- **5.2.2.1. Rôles** : Vérifier que chaque rôle (dégâts, protection, soin, etc.) est couvert.
- **5.2.2.2. Voies élémentaires** : Répartition des sorts, cohérence thématique.
- **5.2.2.3. Spécialisations** : Puissance des capacités/aptitudes par niveau.
- **5.2.2.4. Comparaison** : Méthode pour comparer deux classes/spécialisations.

## 5.2.2.1. Rôles

Vérifie que chaque classe puisse remplir au moins un rôle dans le groupe — ton écosystème de classes doit couvrir le tableau.

### Rôles principaux

**Dégâts** :
- **Fonction** : Infliger des dégâts aux ennemis
- **Classes** : Classes orientées dégâts (Iop, Cra, etc.)
- **Équilibrage** : Dégâts moyens par niveau appropriés

**Protection** :
- **Fonction** : Protéger les allié·e·s
- **Classes** : Classes orientées protection (Pandawa, Sacrieur, etc.)
- **Équilibrage** : [[kref:characteristic:armor_class_creature|CA]] et [[kref:characteristic:life_points_creature|PV]] appropriés, aptitudes de protection

**Soin** :
- **Fonction** : Soigner les allié·e·s
- **Classes** : Classes orientées soin (Eniripsa, etc.)
- **Équilibrage** : Aptitudes de soin appropriées

**Support** :
- **Fonction** : Soutenir les allié·e·s (buffs, débuffs)
- **Classes** : Classes orientées support (Enutrof, etc.)
- **Équilibrage** : Effets de support appropriés

**Contrôle** :
- **Fonction** : Contrôler le champ de bataille
- **Classes** : Classes orientées contrôle (Sram, etc.)
- **Équilibrage** : Aptitudes de contrôle appropriées

### Vérification de couverture

**Méthode** :
- **Liste** : Liste tous les rôles
- **Vérification** : Vérifie que chaque rôle est couvert par au moins une classe
- **Équilibrage** : Assure-toi que les rôles restent équilibrés

**Exemples** :
- **Dégâts** : Iop, Cra, Xélor
- **Protection** : Pandawa, Sacrieur
- **Soin** : Eniripsa
- **Support** : Enutrof, Féca
- **Contrôle** : Sram, Ecaflip

## 5.2.2.2. Voies élémentaires

Les voies élémentaires structurent la répartition des sorts et la cohérence thématique de chaque classe.

### Répartition des sorts

**Voies élémentaires** :
- **Feu** : Sorts de feu, dégâts, brûlure
- **Eau** : Sorts d'eau, soins, gel
- **Terre** : Sorts de terre, protection, contrôle
- **Air** : Sorts d'air, mobilité, foudre
- **Neutre** : Sorts neutres, polyvalence

**Répartition** :
- **Équilibre** : Chaque voie doit avoir des sorts équilibrés
- **Niveaux** : Sorts de tous les niveaux pour chaque voie
- **Variété** : Variété de sorts pour chaque voie

### Cohérence thématique

**Thèmes** :
- **Feu** : Agressif, destructeur, passionné
- **Eau** : Soignant, fluide, adaptatif
- **Terre** : Protecteur, stable, résistant
- **Air** : Mobile, rapide, libre
- **Neutre** : Équilibré, polyvalent, universel

**Application** :
- **Sorts** : Les sorts doivent correspondre au thème
- **Aptitudes** : Les aptitudes doivent correspondre au thème
- **Esthétique** : L'esthétique doit correspondre au thème

## 5.2.2.3. Spécialisations

Les spécialisations ajoutent de la variété — tu peux calibrer leur puissance palier par palier.

### Structure imposée

Toutes les spécialisations partagent le même squelette : **7 paliers** aux niveaux **1, 3, 6, 9, 12, 15, 20**. À chaque palier :
- **choix entre** les capacités garanties + **choix entre** les options (capacités, ou un trait dès le palier 12 ; jamais de points de caractéristique) ;
- **1 compétence** — 3 au palier 1 ; 2 seulement si la fiche l'écrit ; expertise possible aux paliers 9, 15, 20.

Les paliers **3, 9 et 15** portent en plus **1 aptitude automatique** : exactement **3 aptitudes** par spécialisation, jamais plus.

Une spécialisation qui propose plusieurs options à chaque palier est plus « riche » qu'une autre : c'est voulu. Une fiche pauvre en options offre le repli (compétence, puis trait dès le 12), pas des points de caractéristique.

### Puissance des capacités

**Par palier** :
- **Paliers 1-3** : Capacités de base, effets simples
- **Paliers 6-9** : Capacités améliorées, effets modérés
- **Paliers 12-15** : Capacités avancées, effets puissants
- **Palier 20** : Capacité finale, effet exceptionnel

**Équilibrage** :
- **Coût** : Coût approprié selon la puissance
- **Fréquence** : Fréquence appropriée selon la puissance
- **Effets** : Effets appropriés selon le palier

### Puissance des aptitudes

Les trois aptitudes sont gratuites et imposées : elles doivent donc rester plus faibles qu'une capacité du même palier.

- **Niveau 3** : aptitude de base, un bonus lisible (résistance, avantage conditionnel)
- **Niveau 9** : aptitude intermédiaire, effet plus large ou seconde condition
- **Niveau 15** : aptitude avancée, sans jamais valoir un sort actif

**Équilibrage** :
- **Passifs** : Effets passifs appropriés
- **Contextuels** : Effets contextuels avec conditions appropriées
- **Jamais de coût** : Si l'effet mérite un coût, c'est une capacité, pas une aptitude

### Rôles dans les spécialisations

**1er Rôle** :
- **Définition** : Personne jouant la classe dans cette orientation
- **Sorts** : Sorts en accord avec le rôle
- **Caractéristiques** : Caractéristiques en accord avec le rôle
- **Puissance** : Puissance maximale pour ce rôle

**2nd Rôle** :
- **Définition** : Personne jouant la classe d'une autre façon
- **Sorts** : Sorts partiellement en accord avec le rôle
- **Caractéristiques** : Caractéristiques partiellement en accord
- **Puissance** : Puissance modérée pour ce rôle

**Pas de Rôle** :
- **Définition** : Personne ayant choisi d'ignorer ce gameplay
- **Sorts** : Sorts non orientés vers ce rôle
- **Caractéristiques** : Caractéristiques non orientées vers ce rôle
- **Puissance** : Puissance minimale pour ce rôle

## 5.2.2.4. Comparaison

Quand tu hésites entre deux classes ou spécialisations, compare-les sur des critères objectifs.

### Méthode de comparaison

**Critères** :
- **Dégâts** : Dégâts moyens par tour
- **Défense** : [[kref:characteristic:armor_class_creature|CA]], [[kref:characteristic:life_points_creature|PV]], résistances
- **Utilité** : Aptitudes utilitaires
- **Ressources** : [[kref:characteristic:action_points_creature|PA]], [[kref:characteristic:movement_points_creature|PM]], Wakfu

**Valeurs** :
- **Maximum** : Valeur maximum possible
- **Minimum** : Valeur minimum possible
- **Moyenne** : Valeur moyenne

**Évaluation** :
- **Comparaison** : Compare les valeurs entre classes
- **Équilibre** : Vérifie l'équilibre
- **Ajustements** : Ajuste si nécessaire

### Exemple de comparaison

**Iop (Dégâts)** :
- **Dégâts** : Maximum élevé, minimum modéré, moyenne élevée
- **Défense** : Maximum modéré, minimum faible, moyenne modérée
- **Utilité** : Maximum faible, minimum faible, moyenne faible
- **Ressources** : [[kref:characteristic:action_points_creature|PA]] élevés, [[kref:characteristic:movement_points_creature|PM]] modérés, Wakfu modéré

**Eniripsa (Soin)** :
- **Dégâts** : Maximum modéré, minimum faible, moyenne modérée
- **Défense** : Maximum modéré, minimum modéré, moyenne modérée
- **Utilité** : Maximum élevé, minimum modéré, moyenne élevée
- **Ressources** : [[kref:characteristic:action_points_creature|PA]] modérés, [[kref:characteristic:movement_points_creature|PM]] modérés, Wakfu élevé

**Équilibre** :
- **Iop** : Fort en dégâts, faible en utilité
- **Eniripsa** : Fort en utilité, modéré en dégâts
- **Conclusion** : Équilibre approprié, rôles complémentaires
