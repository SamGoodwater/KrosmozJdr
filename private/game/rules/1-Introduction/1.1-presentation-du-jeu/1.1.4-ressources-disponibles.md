## 1.1.4.2. Fiches et outils

Tous les fichiers à télécharger sont regroupés sur la page [[kref:page:ressources-de-jeu|Ressources]] du menu Règles.

### Livre de règles

Le livre complet est compilé à partir des chapitres en ligne :

- **Format PDF** : lecture et impression
- **Format ODT** : ouverture dans LibreOffice ou Word, pour annoter ou extraire un chapitre

Ces fichiers ne sont pas régénérés à chaque visite : un administrateur (ou `php artisan rules:compile-downloads`) les met à jour quand les règles changent.

### Fiches de personnage

Deux formats sont disponibles :

- **Format PDF** : Fiche imprimable pour jouer en présentiel
- **Format PPTX** : Fiche modifiable (PowerPoint) pour personnalisation

Les fiches incluent :

- Toutes les caractéristiques principales et secondaires
- Espaces pour les sorts, aptitudes et capacités
- Section équipement et panoplies
- Espace pour l'historique et les notes

### Générateurs

Disponibles ou en développement :

- **Générateur de personnages** : Création rapide de personnages de niveau 1
- **Générateur de rencontres** : Création de combats équilibrés
- **Générateur de trésors** : Distribution de butin selon le niveau

### Outils complémentaires

- **Calculateurs** : Modificateurs, DD, etc.
- **Tables de référence** : Tables rapides en MJ
- **Aides de jeu** : Résumés des règles essentielles

## 1.1.4.3. Communauté

KrosmozJDR a une **communauté active** et ouverte — n'hésite pas à y participer.

### Discord

Le serveur Discord est le lieu principal d'échange :

- **Discussions** : Règles, parties, stratégies
- **Partage** : Scénarios, personnages, retours de table
- **Annonces** : Nouvelles versions, mises à jour, événements

**Lien** : [#XVu4VWFskj](https://discord.gg/XVu4VWFskj)

### GitHub

Le projet est open source sur GitHub :
